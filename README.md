# Web Application Testing Project - E-commerce Website

## Project Overview
This is a portfolio-ready QA testing project for a sample e-commerce website. The project includes both a frontend demo website and testing artifacts for manual testing, API testing, defect reporting, regression testing, smoke testing, and cross-browser compatibility testing.

## Live Website
[View the deployed e-commerce QA demo](https://webqualityassurance.vercel.app/)

## Application Under Test
Sample e-commerce website built with HTML, CSS, and JavaScript. It includes the following modules:

- User registration and login
- Product search and filtering
- Product details page
- Shopping cart
- Checkout
- Order confirmation
- User profile and order history

## Project Files
- `index.html` - frontend website
- `styles.css` - website styling
- `script.js` - website functionality
- `docs/Test_Plan.md` - scope, strategy, environment, entry and exit criteria
- `docs/JIRA_Defect_Report.md` - 15 sample defects written in JIRA style
- `test-data/ecommerce_test_data.csv` - reusable test data
- `postman/Ecommerce_API_Testing.postman_collection.json` - API requests and test scripts
- `outputs/Ecommerce_Website_Testing_Project.xlsx` - Excel workbook with test cases, defects, RTM, and summary
